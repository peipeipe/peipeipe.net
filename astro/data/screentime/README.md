# スクリーンタイム

1日1ファイル、`YYYY-MM-DD.json`。ショートカットから専用の受信APIにPOSTし、WorkerがGitHubへ保存する。
設定手順: [scripts/SCREENTIME.md](../../../scripts/SCREENTIME.md)

```json
{
  "date": "2026-10-17",
  "device": "iPhone",
  "apps": [{ "app": "Chrome", "minutes": 152.482265720765 }]
}
```

上記は形式の例であり、実データとしては登録しない。`date` とファイル名は一致させる。
日本時間の1日分・iPhone 1台・アプリのみ（Webサイトを混ぜない）。
`minutes` は0〜1440の数値。同一アプリの重複は拒否する。
空の `apps` は実測0分。未取得日はファイルを作らない。
同じ日の再送は既存ファイルを置き換える。複数端末の合算には対応していない。
このディレクトリの内容はGitHubの公開履歴に残り、アプリ名と使用時間もサイトに表示される。
